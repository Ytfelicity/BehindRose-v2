# 代理网络质量

在现有“网络检测”页顶部点击 **代理网络质量**，填写本机 HTTP 代理端口后开始。默认端口 `7897`，与现有 IP 质量体检的常用端口一致，但两者的端口分别选择。

要比较某个代理节点，请先在代理客户端手动选择全局并固定节点。规则分流可能让国内目标直连，也可能让各目标走不同节点；本工具不会改变客户端模式或系统配置。

## 功能

- **出口 / BGP**：通过所填代理访问 ipify，查询当前 IPv4；通过 RIPEstat 查询宣告前缀、所有返回的 ASN（最多 16 个）及首个 ASN 的机构。开始和结束查询同一 ipify 服务，显示是否观察到出口变化。结束查询失败保持未知。
- **三网响应**：快速模式为北京、上海、广东三网共 9 节点；全国模式为 31 省三网共 93 节点。每节点 3 次，最多 6 节点并发，每次最长 4 秒。
- **国际服务**：Cloudflare、Google、Apple、Microsoft、GitHub 五个公开域名的 TLS 握手，均校验证书。CDN 的当次解析可能改变服务地区。
- **下载 / 上传**：手动勾选启用，顺序采样中科大与清华公开镜像、Cloudflare 下载和上传。每个下载最多读取 8 MiB，上传 4 MiB 随机载荷，总采样载荷最多 28 MiB，另有请求头、TLS、代理开销和网络缓冲。每项最长 20 秒。默认不测速。
- **控制与报告**：进度、停止、部分结果、刷新恢复、出口变化提示、文本 / JSON 复制。结果只保留在普通权限后端内存，关闭服务后清除。

## 读数口径

通过 HTTP CONNECT 建立隧道后，国内节点继续发送 `HEAD /`，直到目标的有效 HTTP 响应头完整返回才结束计时。国际服务继续完成 TLS 握手和证书验证。这样不会仅凭代理提前返回的 CONNECT 200 响应产生虚假的低时延。HTTP 状态码只证明目标返回响应，不证明服务解锁。

均值与最低值只取成功样本，0 保留为 0；未知保持空值。抖动为相邻两次均成功的样本差的绝对值均值，中间失败不会跨过去计算。失败率是请求失败比例，**不是 ICMP 丢包率**。国内 HTTP 与国际 TLS 口径分别标明，不能混作纯网络 RTT。

吞吐按实际接收字节（或成功提交的上传载荷）除以从请求开始到采样完成的时间，包含握手，是单连接端到端吞吐采样。节点返回错误状态、HTML、编码响应、样本不足或超时显示未知，不记为 0 Mbps。禁用重定向、自动解压和 Cookie；不会将测速数据写入磁盘。

## 与截图中的 NetQuality 区别

截图来自在 VPS 内执行的 xykt/NetQuality。本模块测量当前电脑使用代理访问目标的路径。国内镜像下载不代表电信 / 联通 / 移动三网 Speedtest，Cloudflare 为就近边缘，不代表固定国家。

NAT 类型、BBR / 队列算法、TCP 缓冲区、真实逐跳回程、CN2 / 9929 / CMI 线路均标注为需要在 VPS 内检测；不使用 Windows、本机 Docker 或 IP 归属推断这些结论。

所有 HTTP 数据请求使用显式 `127.0.0.1:<端口>` 代理，连接探针也只连接该回环端口，并将目标域名交给代理。不会回退到直连，也不安装软件或运行上游在线脚本。仅支持无需认证的本机 HTTP / mixed 端口，不支持纯 SOCKS 端口。当前提供 IPv4 出口及国内 IPv4 节点，国际域名的地址族由代理选择。

## 实现与来源

这是独立编写的 .NET / React 模块，没有复制或执行 NetQuality 的脚本代码。

- 三网域名与省份对应关系参考 [xykt/NetQuality](https://github.com/xykt/NetQuality) 的公开探测节点（`<省份>-ct/cu/cm-v4.ip.zstaticcdn.com:80`）。节点运营者未保证长期可用，失败保持未知。
- [RIPEstat Network Info](https://stat.ripe.net/docs/data-api/api-endpoints/network-info)、[AS Overview](https://stat.ripe.net/docs/data-api/api-endpoints/as-overview)。BGP 是数据库观测，不是当前流量路径。
- [Cloudflare speedtest](https://github.com/cloudflare/speedtest) 的公开 `__down` / `__up` 接口。
- [中科大镜像站](https://mirrors.ustc.edu.cn/)、[清华镜像站](https://mirrors.tuna.tsinghua.edu.cn/) 的 Ubuntu `ls-lR.gz` 公开文件。第三方可能限制速度或访问。
