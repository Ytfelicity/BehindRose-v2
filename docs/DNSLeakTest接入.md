# DNSLeakTest 接入（历史记录）

2026-10-18 已切换到 [IPLeak DNS](IPLeak-DNS接入.md)，旧前端、后端转发入口与客户端已移除。以下仅为原实现记录。

DNS 解析来源使用 [dnsleaktest.com](https://dnsleaktest.com/) 的真实服务。自行实现其公开浏览器协议，应用不加载或打包官网页面、运行脚本及第三方统计脚本。WebRTC 和网站连通性继续使用固定版本 MyIP。

## 标准测试

1. 浏览器产生 6 个 UUIDv4，由本地服务向固定 `https://dnsleaktest.com/api/v1/identifiers` 注册。
2. 浏览器顺序用 Image 请求 `https://<UUID>.test.dnsleaktest.com`，与 HTTPS 官网的探针地址一致。图片成功或失败均推进；图片失败不能直接推断 DNS 解析失败。与官网一样等待每张图片的 load/error，不用本地 8 秒计时跳过图片。用户仍可随时停止。
3. 本地服务向固定 `/api/v1/servers-for-round` 查询本轮计数，再向 `/api/v1/servers-for-result` 获取完整解析器数组。轮次 count 是观察到的解析器数量，不是完成的查询数量，不能要求 count 达到 6 才取结果。
4. 后端在响应大小、记录数量、JSON 深度和 IP 格式校验后转发原始 JSON；不修改 IP 文本，不删重复或空占位行，不裁剪、替换或丢弃字段。前端保留返回顺序，不自行去重、归组、排序或用本地 DB-IP 补地区。
5. 结果表使用官网的 IP、Hostname、ISP、Country 四列。Country 按官网规则显示 `city + ", " + country`，无 city 时只显示 country，保持原文；该列右对齐，文本后按服务 country_code 显示对应的本地国旗资源。Hostname 超过 20 字符时显示前 20 字符和 `...`。悬停及复制报告仍可查看完整主机名。所有服务文本通过 textContent 显示。

标准测试为 1 轮 6 个域名。官网扩展测试为 6 轮，本工具当前使用标准测试。[官网说明](https://dnsleaktest.com/what-is-the-difference.html)及[协议依据](https://dnsleaktest.com/assets/js/app.js)于 2026-10-17 静态核对；参考脚本与 SHA-256 记录存放在 `artifacts/dnsleaktest-reference/`，不加载或执行该脚本。

## 浏览器与本地服务的职责

官方结果接口不提供跨域授权，页面禁止 iframe。本工具的普通权限后端只转发三个固定的 JSON API；不获取官网 HTML，不向任意 URL 转发，也不在后台解析或请求测试域名。随机域名请求始终由当前浏览器或桌面 WebView2 发出，保持该环境的 DNS 路径。

开发网页保留同源、Origin 和会话 token 校验；桌面消息保留来源、任务 epoch 和 requestId 校验。控制接口仅接受 1–6 个唯一 UUIDv4，单次最长 8 秒，响应最多 256 KiB、256 条解析器记录。DNS 图片 CSP 仅额外开放 `https://*.test.dnsleaktest.com`。

后端控制连接分别解析 IPv4 和 IPv6，优先尝试 IPv4并保留 IPv6 回退，避免单个地址族的查询卡住整个接口。仍使用原系统代理和标准 TLS 校验；此策略只用于控制 API，不改变浏览器探针或结果中的 IPv6 解析器。

停止会结束前端等待并清理图片回调，后续探针和查询不再发出；已开始的后端控制请求有独立时间上限。迟到的返回不会污染下一次测试。IP、DNS、WebRTC 完成后才启动网站连通性。选择 DNS 时不设置跳过探针的核心阶段总时限；不选 DNS 时核心阶段与网站阶段仍各最多 55 秒。

与官网不同的应用层边界：本地控制请求保留 8 秒超时、前端转发等待保留 10 秒超时，取消、无效响应或接口错误明确显示无法确认；不模仿官网把请求错误吞成空数组的做法。这些边界不会改写成功响应或产生伪造的通过结果。

## 结果范围

显示全部服务返回记录，机构、地区及 DNSSEC 字段保留服务原值；缺失字段保持为空。图片收到错误会按官网流程继续查询，不能直接判断解析失败。只有空占位行、空数组和接口失败都显示无法确认，不能当作无泄漏。结果只代表本次浏览器采样，不覆盖全部系统请求。服务会收到必要的临时标识、解析请求和来源地址。

相同协议不意味着两次独立采样的 IP 清单必然逐项相同。域名标识、采样时间、浏览器 DNS/DoH、代理分流和解析服务负载均衡都会影响采样；官网也说明单个配置的解析器可能转交多个服务器。本工具不修改系统代理、DNS、节点、TUN 或浏览器设置来强行对齐结果。
