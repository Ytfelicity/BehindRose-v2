来源为本项目保存的 [详细手册原文](claude-handbook/handbook.md) 和 [X 经验整理原文](claude-handbook/experience-summary.json)，资料核对日期为 **2026-10-24**。工具箱保留全部 13 节原文、21 段原始命令和 8 张配图的来源说明；结构化步骤用于导航，完整原文用于核对表格、警告及上下文。

文章主线是 **Windows 原生 PowerShell + Clash Verge / 同类客户端 + 官方 Claude Code + 自己的 Claude 订阅**。已有网关接入仅在手动读取的脱敏摘要中提示，不能替代文章主线。配置写入成功不能标记为网络、订阅、账号或模型验证成功。

所有文章命令仅展示或复制，不因进入页面、切换章节、展开说明、勾选清单或生成预览而执行。安装、登录、付款、网络检查与申诉均由用户日后主动操作；开发和验证不测试真实网络，不修改当前代理或账号配置。

## 必须放在开头的说明

1. 不存在照做就绝不封号的配置，短期个案不构成成功率。
2. 先核对 Claude 支持地区与使用资格；代理连通不等于取得使用资格。关于地区的表述保留原文核对日期。
3. 主线使用自己的官方订阅，WSL、API 中转和云厂商认证不能直接套用。
4. 正常工作的机器跳到日常启动，不为凑教程重置；明确封禁先申诉，不先删配置。
5. 清理前完整备份，不分享授权 URL、授权码、API Key、.credentials.json 或备份包；网络排错不能证明账号安全。

- `frontend/src/claude-handbook-data.ts`：静态结构化数据；每节 `sourceMarkdown` 保留完整原文；命令均为 `execution: 'display-only'`，涉及网络时 `network: true`。
