# 检测页视觉与信息层级

这次只更新开发源码，没有生成新发布包。

主要调整：

- 首屏以公网 IP 为主要信息，提供独立复制地址按钮；地区与网络归属另成一层。
- 加入本地功能图标和国旗。DNS 国旗使用服务返回的国家信息；公网 IP 只有成功查询到地区后才显示国旗，不根据 IP 或解析器猜测。
- DNS 按国家和 ASN 网络机构归组，首先展示机构、地区及地址数量，展开查看完整地址。
- WebRTC 出口不同的来源排在最前，并在首屏显示需要核对的提示；取得结果与出口一致分别表达。
- 检测参数、任务进度、来源及解释分层；较长解释默认折叠。
- DNS 与 WebRTC 在宽屏并排，在窄侧栏上下排列；支持现有浅色/深色主题。

验证：

- 使用真实采样检查了国旗显示、机构归组与差异提醒；18 个解析器正确归为 3 个机构/地区组合，展开地址总数仍为 18。
- 日本、美国图标均从本地加载成功，不增加外部图片服务请求。
- 540 像素侧栏内未发现横向溢出，图标和状态仍可读。
- 31 项请求、解析、地区映射及 DNS 分组断言通过；Debug 构建与桌面组件加载检查通过。
