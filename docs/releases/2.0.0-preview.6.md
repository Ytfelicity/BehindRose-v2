# 2.0.0-preview.6

本版将已完成的安全修复交付到 Windows 安装包和便携包，建议旧预览版用户更新。

- 配置文件读写期间锁定父目录，并在实际文件句柄上拒绝重解析文件和硬链接；原子替换始终保持临时文件打开，避免目录检查与操作之间的路径替换风险。
- Release 构建使用统一的虚拟源码路径，避免自有程序集的调试元数据带出作者本机工程目录。
- 源码提交检查增加完整历史、未知扩展名文本、代理订阅及提交邮箱检查；GitHub 安全检查持续运行。
- 公开名称统一为 Rose in my wake，保留左上角原有的手写图形 Logo；更新标识、配置和备份目录保持兼容。

安装版和便携版均包含相同的安全修复。已有支持更新的版本可以在程序中检查更新；下载更新后仍需用户确认安装。

安装包尚未数字签名。网络检测与详细报告的隐私范围见仓库中的 SECURITY.md 和使用说明。
