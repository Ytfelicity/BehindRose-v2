# 2.0.0-preview.7

本版将沿用本机代理的 DNS 防护、完整备份恢复和 TUN 兼容更新交付到 Windows x64 安装包及便携包。

- **本机完整备份与一键恢复**：在“恢复记录”中加密保存订阅、节点、脚本、规则、DNS、TUN 与配置目录资源。配置目录丢失后可从备份重建；恢复前显示范围并再保存当前状态，发生错误时尝试回滚。修改 Clash 配置前也会自动创建完整备份。
- **DNS 增量防护**：沿用本机现有代理组及原订阅脚本，保留原有节点和分流，为 6 个隐私检测站点补充代理与 DNS 规则，同时补充广告过滤及网易／战网直连例外。检测浏览器使用已识别的本机 HTTP／混合代理端口。
- **TUN 兼容与配置预览**：支持 System、GVisor、Mixed、Mips，保留网卡名、MTU、排除网段和手动出口；预览逐项显示虚拟网卡、路由与 DNS 接管设置。已有配置也可通过“再次配置”重新生成方案。
- **检测界面与 Claude Code 离线手册**：更新网站连通性和浏览器 DNS 检测展示；提供 13 节 Windows 手册、8 张配图与可下载脚本。脚本由用户手动执行，可选时区调整需单独预览、确认并支持恢复。

私人节点、订阅及认证信息不包含在源码和安装包中，完整备份不上传。备份依赖创建它的 Windows 用户密钥，重装系统或更换账号前需另行保存可迁移备份。首次使用仍需自行导入订阅。

配置已保存不代表实际网络无泄漏；应用后请重新打开 Clash，并检测实际 DNS 和网络出口。特殊配置无法安全识别时会停止修改并说明原因。

已有支持更新的预览版可在程序中检查更新；也可下载新版安装包或完整解压便携包。安装包尚未数字签名。
