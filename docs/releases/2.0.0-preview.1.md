# 2.0.0-preview.1

身后红玫瑰 · 网络助手首个支持更新的开发预览包。

- 保留禁止商用的源码公开许可及第三方原许可。
- 支持启动检查 GitHub Releases、提示新版本、确认后下载校验并更新重启。
- 支持暂缓和取消，配置操作期间暂缓更新。
- 支持 Windows x64；配置修复、真实 UAC 与不同客户端的生效范围仍按验证范围说明。

首次使用请下载本 Release 的安装包或完整便携包，保留全部文件。旧版普通 ZIP 不包含自动更新布局。

此版本用于公开预览及跨版本更新验收。可用 `BehindRose.exe --update-test` 在内存演示配置下测试真实 GitHub 更新；该模式不写用户配置、偏好或备份，重启后继续保持测试模式。日常使用普通双击启动。
