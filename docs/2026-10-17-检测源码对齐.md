## 应用适配边界

以下边界保留并明示，没有把它们描述成逐字等同官网：

- 不复制原版的自动启动采样、遥测、在线报告上传或自动安装／更新。保留用户点击开始、手动停止、取消隔离和资源限制。
- MyIP 原版 async setInterval 在慢轮次结束前继续触发，完成后才递增计数，可能超出预期轮数。本工具按原版预期保留固定 10 轮，并在派发时预留轮号，等待所有请求结束；不复制超发问题。
- WebRTC 的在线 MaxMind 归属扩展未接入，STUN 算法原文不变；本地地区是独立的 DB-IP 估计，不冒称与 MyIP 的机构／地区结果相同。候选类型不当作完整 NAT 分类。
- IPQuality 指定代理时，HTTP 包装器统一添加该次容器内请求的代理参数，覆盖原版个别查询漏带 CurlARG 的情况。不写注册表、配置文件、节点、TUN、路由或浏览器代理设置。
- 容器不能绑定未分配给它的公网地址；SMTP 使用容器普通出站连接，不绑定本机或容器 25 源端口。代理模式下不执行 SMTP，不推断代理的 25 端口状态。
- DNSBL 的超时、SERVFAIL、非正常退出及 127.255.255.* 限制应答保持未知，不复制原版将限制回复当 Clean 的错误处理。Fake-IP 仅在本次查询内部按既有 DoH 回退处理；不改系统 DNS。IPv6 DNSBL 未提供。
- 保留已修正的 IPQS JSON 变量错误，取真实 ipqs[score]；JSON 使用安全编码，不复制原版字符串插入风险。缺少注册地区时保持未知，不猜测原生／广播。

## 验证

验证只使用固定源码、模拟 HTTPS/STUN、原始 CSV、本地内存模型及 `--network none` 的临时容器。没有运行真实公网检测，没有连接 VPS，没有配置写入命令；.NET 的修复／TUN 测试使用 MemoryState，不接触本机配置。

- 连通性离线测试：原函数与地址、10 轮、首轮屏障、后续轮次重叠、完整超时样本、实测数值、200 ms、停止。
- MyIP 离线测试：STUN 原文与来源、首个映射候选、IPv6、超时、禁用和取消；历史 DNS 源码也保留回归。
- DNSLeakTest 离线协议测试通过。
- DB-IP 原始 CSV 774 组对照及本地数据哈希校验通过。
- IPQuality 断网容器测试：原版出口来源顺序、完整／精简分支、各库数据编码、显式代理请求参数、分值／null／false、服务逐项与中断结果、DNS 错误通过；另以全部固定 DNSBL 域名的本地 NXDOMAIN 样本验证 50 并发聚合，未丢失记录。
- 浏览器模拟测试：连通性、IP 质量、完整工作台通过。修正了旧 IP 质量测试未模拟新端口发现接口的问题；所有 API 均拦截，未读取或改写真实代理端口。
- .NET 离线测试 49/49 通过；实际文件原子写入用例只写项目 test-files 中的独立临时文件。
- 最终 TypeScript 检查、前端构建及整套 .NET 工程构建通过，0 警告、0 错误。仅在确认无配置操作和 IP 质量任务运行后更新本地开发服务，使新容器脚本及 PID 限制生效；未更改其它进程或代理配置。

这些检查证明固定源码及适配行为的对应关系，不等于对第三方接口当前在线可用性、所有浏览器路径或账号权限的实测认证。

审查结果：实现意图方面定位并修正五类偏差（连通性采样、IPQuality 出口来源、完整／精简分支、显式代理遗漏、DNSBL 错误处理）；规范方面未发现需保留的独立阻断问题。原样保留的应用边界与远端辅助文件校验缺口已列明。
