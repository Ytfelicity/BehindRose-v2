## 本地验证项目

2026-09-22 完整浏览器工作台增量验证：Debug 解决方案构建零警告、零错误；原 28 项 C# 核心测试、31 项网络检测 JavaScript 断言通过。新增 `tests/local-workbench.test.mjs` 验证内存中的体检、只读预览、应用、幂等、备份、恢复、预览令牌重用拦截及不向前端返回配置快照；独立临时回环服务验证 Host / Origin、CSRF、预检、内容类型、请求大小及命令白名单。

浏览器实测读取本机体检和修复预览、空备份页、设置页及内嵌网络检测页面；检查默认宽度和 540 px 窄窗口、深浅主题同步、页面控制台。真实配置写入和 UAC 授权仍未在用户环境执行；其流程复用已有 Windows 工作进程，需在独立测试环境验收。当前改动只更新源码与 Debug 构建，不更新发布包。

## 仍需独立环境运行验收

- 真实 Windows UAC 提权、ProgramData ACL 与真实浏览器注册表策略的写入和恢复。
- Clash Verge Rev 2.5.2 在退出、重新打开、服务持续运行等情况下的配置生效。
- Chrome、Edge、Firefox 重启后实际策略和网络行为。
- 各第三方服务的可达性、CORS、限流、真实 DNS 域名采样、IPv6 和 STUN 情况。
- 干净系统缺少 WebView2、不同 DPI、多显示器和系统主题动态切换等场景。
- 断电、磁盘故障、系统强制结束与并发外部修改。
- 签名、安装包、升级与卸载验收。本次交付以便携包为主；安装脚本尚需已安装的打包器构建验证。

本轮不在用户正在使用的 Clash 和浏览器上执行真实修复，也不停止这些进程。
