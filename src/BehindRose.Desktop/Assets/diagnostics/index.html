如何理解这些解析器

使用 IPLeak.net 的连续采样协议：同一 40 位会话标识，每次请求使用新的域名序号，最多 300 次；第 100 次起间隔 1 秒。结果实时显示，可随时停止并保留已取得的记录。每张卡片对应官网返回的解析器，命中次数直接采用上游累积值；地区和 ISP 来自 IPLeak 公开 JSON 接口，不使用本地数据库补全。归属查询失败不影响已取得的 IP 和命中次数。独立采样的时间、浏览器和轮数不同，解析器列表可能不同；解析器与公网出口不同、数量多，都不能单独证明泄漏。

数据来源、隐私与检测范围
公网地址
ipify 提供 IPv4 / IPv6。IPv6 请求失败也可能只是没有 IPv6 路由。
国家与国旗
使用随包提供的 DB-IP Lite 国家数据库在本地匹配 IPv4 / IPv6；不向第三方发送 IP。没有匹配时显示地区未取得。
IP 质量与归属
点击 IP 质量体检后，通过 IPPure 官方公开接口查询出口归属、风险系数和类型。仅当体检出口与浏览器 IP 相同时，才补充这里的城市和网络归属；未知值保持未知。
DNS 采样
使用 IPLeak.net 的真实检测服务。当前浏览器直接以同一会话请求新的 DNS 检测子域名，顺序采样最多 300 次，保留官网返回的 IP 与累积命中次数。地区和 ISP 使用 IPLeak 公开 JSON 接口；本机后端不发起或转发 DNS 采样，也不修改代理或 DNS 设置。服务方会收到临时标识、解析请求、解析器 IP 和来源地址。不同浏览器、时间与采样次数可能得到不同结果。
WebRTC
直接复用 MyIP 的 Google、BlackBerry、Twilio、Cloudflare STUN 地址与采样函数；四源并行，每源最长 5 秒，记录首个 srflx/prflx 映射候选。候选类型不等于完整 NAT 类型。服务可能被限流或网络阻断。Cloudflare 来源说明。
网站连通性
直接复用 MyIP 的浏览器 GET 检测与内置探测地址，不携带账号 Cookie。默认每站最多 3 次取最低成功耗时，整组最多 5 秒；可选单次或最多 10 次（整组最多 8 秒），单站重测为单次，每次超时 3.6 秒。耗时不是 ICMP Ping；跨域状态码不可见，不验证登录、地区权限或 AI 功能可用性。自定义列表保存在本机，检测结果只保留在本次页面内存。
界面与图标
页面和图标均来自本地文件，国旗使用随包提供的 flag-icons（MIT）。检测实现参考 MyIP，许可见项目目录。
